# Processors

> Services that process personal data for the site, and the terms that bind them (COPPA 312.8 asks for written assurances). Reviewed yearly with the [security programme](security-programme.md).

| Service | What it does for us | Data | Where | Terms on file |
| --- | --- | --- | --- | --- |
| **Supabase** | Database, sign-in, server functions, vault | All account data, child profiles, consent records | US (AWS, Oregon) | [Terms of service](https://supabase.com/terms), [Data processing addendum](https://supabase.com/legal/dpa), [Privacy policy](https://supabase.com/privacy) |
| **Google (Gmail)** | Sends the site's emails (sign-in, guardian and parent confirmations, codes) | Recipients' email addresses and the emails' text | Google's data centres | [Google Workspace / Gmail terms](https://policies.google.com/terms), [Privacy policy](https://policies.google.com/privacy) |
| **GitHub** | Hosts the site (Pages), runs the build, keeps encrypted backups | Visitors' IP addresses (hosting logs); encrypted database backups | US | [Terms of service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service), [Data protection agreement](https://github.com/customer-terms) |
| **Anthropic (Claude)** | The daily triage assistant: reported games and feedback text | Usernames, report notes, chat phrases, feedback text; never emails; never child profiles (children can't play online or be reported) | US | [Commercial terms](https://www.anthropic.com/legal/commercial-terms), [Privacy policy](https://www.anthropic.com/legal/privacy) |
| **Stripe, GitHub Sponsors** | Donations (on their own pages) | Donors' payment details, held by them | US | Their own terms; the site receives no payment data |
| **Google / Cloudflare STUN** | Tell a browser its own network address for direct game links | IP address | Global | Public STUN service; no account data |

Saved copies: keep a PDF of each "terms on file" link in the owner's records at each yearly review, with the date.
